# Dog Breed AI


Production-oriented dog breed classification platform built with TensorFlow/Keras, Django REST Framework, and React.


## Project Status

🚧 In development


## Planned Stack


- TensorFlow / Keras
- Python
- Django REST Framework
- React
- Vite
- Docker
- GitHub Actions
- Power BI


## Model


120-class dog breed classification using an ensemble-based transfer learning architecture. 


## Dataset

The Kaggle dog-breed dataset is used locally for training and evaluation.

Dataset files are internationally excluded from this repository.


## Architecture

```text
React / Vite
      ↓
Django REST API
      ↓
TensorFlow/Keras inference engine
      ↓
Ensemble model
      ↓
Top-5 breed predictions
